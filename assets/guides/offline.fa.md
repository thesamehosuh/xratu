# راهنمای آفلاین و مدل محلی

این راهنما همراه خراتو نصب میشه و بدون اینترنت باز میشه.

۱. وقتی اینترنت داری `Ollama` یا `LM Studio` رو نصب کن و یه مدل کدنویسی دانلود کن. خراتو نمیتونه بدون اینترنت رانتایم یا وزن های مدل رو دانلود کنه.
۲. توی تنظیمات، صفحه سرویس دهنده ها رو باز کن، رانتایم های محلی رو اسکن کن و وصل شو. مدل رو توی انتخابگر گفتگو انتخاب کن. برای `Ollama` روی پورت `11434` بخش مدیریت مدل ها رو باز کن؛ دانلود با نمایش پیشرفت و لغو، و حذف با تایید انجام میشه. مدل های رانتایم های دیگه رو توی خود برنامه مدیریت کن.
۳. حالت آفلاین رو توی تنظیمات روشن کن. نوار بالای صفحه نشون میده که فعاله. فقط نشانی های همین سیستم مثل `localhost`، `127.0.0.1` و `::1` مجازن؛ رانتایم های شبکه محلی یا اینترنت بسته میشن. درخواست ها از پروکسی یا تغییر مسیر استفاده نمیکنن. سرویس ابری، تازه کردن فهرست مدل های اینترنتی، ابزارهای وب و MCP خارجی غیرفعال میشن. اتصال های ذخیره شده پاک نمیشن.
۴. ابزارهای فایل، تاریخچه، نقطه های بازیابی و مدل محلی کار میکنن. برای دانلود مدل جدید یا اتصال ابری حالت آفلاین رو خاموش کن.

این حالت درخواست های شبکه خود خراتو رو کنترل میکنه. دستورهای ترمینال و لینک هایی که خودت توی مرورگر باز میکنی هنوز میتونن به اینترنت وصل بشن؛ محدودیت شبکه سیستم عامل نیست. روشن کردنش گفتگو، دانلود، تست سرعت و ورود فعلی رو لغو میکنه و اتصال های MCP رو میبنده. فروشگاه وقتی دسترسی زنده نداره از فهرست ذخیره شده یا همراه برنامه استفاده میکنه.

## انتخاب مدل با توجه به حافظه

وزن های مدل، حافظه زمینه، بافرهای رانتایم و سیستم عامل همگی جا لازم دارن. `Q4_K_M` نقطه شروع خوبیه؛ `Q8` تقریبا دو برابر برای وزن ها حافظه میخواد. مصرف دقیق VRAM به مدل، اندازه زمینه و مقدار بارگذاری روی کارت گرافیک بستگی داره.

| سخت افزار | نقطه شروع محافظه کارانه | زمینه |
| --- | --- | --- |
| ۸ گیگ RAM، بدون کارت گرافیک | مدل `3B` با Q4؛ مدل `8B` ممکنه حافظه آزاد کافی نداشته باشه | `4–8k` |
| ۱۶ گیگ RAM، پردازنده | مدل `7–8B` با Q4؛ قبل از مدل بزرگ تر حافظه آزاد رو چک کن | `8k` |
| ۸ گیگ VRAM | مدل `7–8B` با Q4 و زمینه کم؛ مدل `14B` معمولا کامل جا نمیشه | `4–8k` |
| ۱۶ گیگ VRAM | مدل `14B` با Q4 ممکنه جا بشه؛ برای زمینه و بافرها جا بذار | اول `8k` |

یه مدل `7–8B` با Q4 معمولا حدود ۴.۵ تا ۵.۵ گیگ فقط برای وزن ها جا میخواد. حداقل ۲ گیگ RAM برای سیستم عامل و رانتایم، و مقداری هم برای زمینه کنار بذار. توی ویندوز `Task Manager` یا ابزار حافظه سیستم رو چک کن. اگه سیستم شروع به استفاده زیاد از دیسک کرد یا حافظه کم آورد، مدل یا زمینه رو کوچک کن. پردازنده ممکنه فقط چند token در ثانیه تولید کنه. Q3 و پایین تر میتونن کیفیت کدنویسی رو کم کنن.

## اگه اتصال محلی کار نکرد

- اتصال رد شد: `Ollama` رو از نوار ویندوز دوباره باز کن یا سرور محلی `LM Studio` رو روشن کن و دوباره اسکن کن.
- مدلی نیست: قبل از آفلاین شدن یه مدل دانلود کن. پشتیبانی فراخوانی ابزار رو هم چک کن.
- خطای زمینه: اندازه دستی زمینه رو کم کن یا مدلی با زمینه بزرگ تر انتخاب کن. زمینه بزرگ تر حافظه بیشتری لازم داره.
- کمبود حافظه: مدل Q4 کوچک تر یا زمینه کمتر انتخاب کن، یا مقدار بارگذاری روی کارت گرافیک رو توی رانتایم کم کن.
- خطای ناشناخته: متن اصلی خطا رو نگه دار. گزینه توضیح خطا ها توی تنظیمات برای خطا های شناخته شده یه توضیح به زبان رابط اضافه میکنه؛ درخواست مدل دیگه لازم نداره.
