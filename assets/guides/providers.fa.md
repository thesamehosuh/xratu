# مقایسه ارائه دهنده ها و پرداخت از ایران

اعتبار API با اشتراک چت فرق داره. قبل از پرداخت چک کن که طرح انتخابی دسترسی API، مدل موردنظر، پاسخ جریانی و فراخوانی ابزار رو پوشش بده. خراتو نشانی سرویس و کلید API لازم داره، نه ورود به سایت.

## مقایسه انتخاب ها

| --- | --- | --- |
| [`AvalAI`](https://avalai.ir/products/) | طبق صفحه رسمی محصول، نرخ API برابر نرخ ارائه دهنده اصلی و بدون کارمزد اضافه هست؛ اعتبار تومانی یا `UNIT` و پرداخت بانکی داخلی داره. نرخ تبدیل، انقضای اعتبار و قیمت هر مدل رو توی [پنل توسعه دهنده](https://chat.avalai.ir/platform) چک کن. | نشانی آماده `https://api.avalai.ir/v1`؛ کلید رو توی پنل API بساز. |

| [`ArvanCloud`](https://www.arvancloud.ir) | قیمت سرویس AI و پرداخت رو توی پنل چک کن. | نشانی اختصاص داده شده به سرویس رو وارد کن. |

| `Ollama` / `LM Studio` | صورتحساب token نداره؛ سخت افزار، برق، دانلود و فضای دیسک هزینه دارن. | یه رانتایم همین سیستم رو وصل کن. راهنمای آفلاین همراه برنامه هست. |

فقط توضیح قیمت و پرداخت `AvalAI` توی این جدول از صفحه رسمی محصولش تایید شده. ردیف های دیگه منبع فعلی رو نشون میدن و قیمت حدسی ندارن. وجود یه گزینه توی خراتو تضمین دسترسی زنده یا مناسب بودن طرح نیست.

## مقایسه هزینه و سرعت واقعی

۱. روی اتصال های مختلف همون مدل رو انتخاب کن. توی صفحه سرویس دهنده ها، بخش مقایسه سرعت رو باز کن و مدل فعال رو تست کن. فقط پیام کوتاه `Reply with OK.` با سقف خروجی ۳۲ token میفرسته؛ محتوای پروژه یا ابزارها رو نمیفرسته. هر تست ممکنه هزینه داشته باشه. زمان رسیدن اولین token متنی و زمان کل از سیستم خودت اندازه گیری میشه. نتیجه ها فقط تا وقتی این صفحه وب بازه میمونن؛ کیفیت استدلال یا سرعت طولانی مدت رو اندازه نمیگیرن.
۲. چند بار با همون شبکه، پروکسی و مدل تست کن و میانه رو مقایسه کن. خطا یا جواب بدون متن، سرعت صفر حساب نمیشه. مسیر مدل و بار سرویس ممکنه بین درخواست ها عوض بشه.
۳. قیمت فعلی ورودی، خروجی و ورودی cache شده رو توی صفحه مصرف وارد کن؛ واحد USD یا IRT رو درست انتخاب کن. هزینه برابر مجموع تعداد token هر بخش ضرب در نرخ اون بخش، تقسیم بر یک میلیون هست. ورودی عادی و cache شده رو جدا حساب کن. نرخ هر هزار token رو با نرخ هر میلیون اشتباه نگیر. هر تومان ۱۰ ریاله.
۴. هزینه کار واقعی رو هم با نرخ اسمی مقایسه کن؛ فراخوانی ابزار و تلاش دوباره میتونه مصرف رو بالا ببره. صفحه مصرف خراتو هزینه مشاهده شده رو نشون میده، ولی تخمین جای صورتحساب ارائه دهنده رو نمیگیره.

## شروع کار و پرداخت

لینک رسمی رو باز کن، ثبت نام کن، اعتبار API رو انتخاب کن و واحد صورتحساب و تاریخ انقضا رو چک کن. اول مقدار کمی اعتبار از مسیر پرداخت پشتیبانی شده بخر. کلید API بساز، کلید و نشانی رو توی صفحه سرویس دهنده ها خراتو وارد کن، وصل شو و مدل رو انتخاب کن. کلید توی حافظه امن `VS Code` میمونه. کلید رو توی گفتگو، ترمینال، اسکرین شات یا این راهنما نذار.
