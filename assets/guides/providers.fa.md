# مقایسه ارائه دهنده ها و پرداخت از ایران

برای سرویس های مبتنی بر کلید API، **اعتبار API و اشتراک چت سایت دو محصول جدا هستن**. قبل از پرداخت مطمئن شو طرح انتخابی دسترسی API، مدل موردنظرت، پاسخ جریانی و فراخوانی ابزار رو پوشش بده. خراتو به نشانی پایه و کلید API نیاز داره، نه ورود به سایت. *(اشتراک `ChatGPT` جداگانه از طریق **ادامه با ChatGPT** وصل میشه.)*

> **نکته تایید اطلاعات:** فقط توضیح قیمت و پرداخت `AvalAI` بالا از صفحه رسمی محصولش تایید شده. بقیه ردیف ها مستقیم به منبع اصلی اشاره میکنن تا قیمت حدسی ننویسیم. وجود پریست توی خراتو تضمین دسترسی زنده نیست؛ قبل از خرید اعتبار همیشه خودت چک کن.

## مراحل سریع شروع کار

۱. لینک رسمی ارائه دهنده رو باز کن و ثبت نام کن.
۲. **اعتبار API** (نه اشتراک چت وب) رو انتخاب کن، واحد صورتحساب و تاریخ انقضای اعتبار رو چک کن و اول مبلغ کمی شارژ کن.
۳. یه کلید API بساز، بعد توی خراتو **تنظیمات ← ارائه دهنده ها** رو باز کن.
۴. پریست رو انتخاب کن، کلید (و در صورت نیاز نشانی پایه) رو وارد کن، وصل شو و مدل رو بردار.

کلیدهای API توی `SecretStorage` خود `VS Code` میمونن. هیچ وقت کلید رو توی گفتگو، ترمینال، اسکرین شات یا راهنما نذار.

## مقایسه واقعی سرعت و هزینه

۱. **تست سرعت بگیر**: روی هر اتصال همون مدل یکسان رو انتخاب کن، توی **ارائه دهنده ها** بخش **مقایسه سرعت اتصال ها** رو باز کن و مدل فعال رو تست کن.
   - فقط پیام کوتاه `Reply with OK.` با سقف خروجی ۳۲ token میفرسته؛ هیچ فایل پروژه یا ابزاری ارسال نمیشه.
   - هر تست ممکنه هزینه کمی داشته باشه و زمان اولین token متنی و زمان کل پاسخ رو از سیستم خودت اندازه میگیره.
   - نتیجه ها تا وقتی همین صفحه بازه میمونن و کیفیت استدلال یا سرعت طولانی مدت رو نمیسنجن.
۲. **میانه رو مقایسه کن، نه یه نمونه رو**: چند بار روی همون شبکه و پروکسی و همون مدل تست بگیر. خطا یا پاسخ بدون متن به عنوان خطا نشون داده میشه، نه سرعت صفر.
۳. **هزینه token رو دقیق حساب کن**: نرخ فعلی ورودی، خروجی و ورودی cache شده رو توی بازنویسی قیمت صفحه **مصرف** وارد کن (با انتخاب واحد `USD` یا `IRT`). روی تعداد token یکسان مقایسه کن:

   ```text
   هزینه = (ورودی_عادی × نرخ_ورودی + ورودی_کش × نرخ_کش + خروجی × نرخ_خروجی) / 1,000,000
   ```

   ورودی عادی و cache شده رو جدا حساب کن تا token های کش شده دو بار شمرده نشن. حواست باشه ارائه دهنده نرخ رو به ازای هر **هزار** یا هر **میلیون** token نوشته، و قیمت به **ریال** هست یا **تومان** (`۱۰ ریال = ۱ تومان`).
۴. **هزینه کار واقعی رو بسنج**: نرخ اسمی همه ماجرا نیست؛ نوبت های پراستفاده از ابزار و تلاش های دوباره token بیشتری مصرف میکنن. صفحه **مصرف** خراتو هزینه مشاهده شده رو نشون میده، ولی تخمین هیچ وقت جای صورتحساب ارائه دهنده رو نمیگیره.
